Tenko MC · TMC Modpack 1.1

How to Install the Modpack

Download the modpack file from the Tenko Discord and import it into your launcher. The file sets up Minecraft and NeoForge for you, so there's no instance to build by hand.

Minecraft: 1.21.1
Loader: NeoForge 21.1.250
Mods: 91
Server address play.tenkominecraft.com
! Don't update any mods yourself, not through your launcher and not by hand. Every mod version is matched to the server. Updating even one can stop you from joining or crash your game. When the pack changes, a new file is posted on Discord.
1

Download the modpack from Discord

Join the Tenko Discord, find the latest modpack post, and download the file for your launcher. Don't unzip it: the launcher reads the file as it is.

CurseForge App
TMC Modpack 1.1CF.zip
Every other launcher (Modrinth App, Prism Launcher, ATLauncher, MultiMC)
TMC Modpack 1.1.mrpack
2

Import it into your launcher

Find your launcher below. Each one installs everything, including NeoForge 21.1.250.

CurseForge App
  1. Open the app and go to the Minecraft tab
  2. Click Create Custom Profile
  3. Click Import at the top of the window and pick TMC Modpack 1.1CF.zip
  4. Wait for it to finish installing
Modrinth App
  1. Click the + button to create a new instance
  2. Choose Import from file and pick TMC Modpack 1.1.mrpack
  3. Wait for it to finish installing
Prism Launcher / MultiMC
  1. Click Add Instance
  2. Choose Import on the left
  3. Browse to TMC Modpack 1.1.mrpack and click OK
ATLauncher
  1. Go to Instances and click Import
  2. Pick TMC Modpack 1.1.mrpack and click Import
3

Turn on the resource packs

The pack includes 3 connected-texture resource packs. In game, open Options → Resource Packs, move these to the Selected side, and click Done:

  • Fusion Block Transitions
  • Fusion Connected Blocks
  • Fusion Connected Glass
4

Launch and connect

  1. Select the modpack instance in your launcher and click Play
  2. Once the game loads, open Multiplayer and click Add Server
  3. Enter play.tenkominecraft.com and join
  4. At spawn, talk to Natsubashi for your Book of Knowledge and starter kit
New to the server's systems? The Mod Wiki explains every mod plus coins, crates, ranks and travel.

Updating to a new version

When a new modpack file is posted on Discord, download it and import it the same way. Then delete the old instance so you don't launch the wrong one. To keep your settings and minimap waypoints, copy options.txt and your Xaero waypoints over first.

Troubleshooting

The game won't launch or crashes right away
Make sure you're launching the imported modpack instance (NeoForge 21.1.250), not a different profile.
"Missing mod" or "incompatible mod" when joining
You're on an older modpack version. Download the latest file from Discord and import it again.
The import fails or does nothing
Check you picked the right file: TMC Modpack 1.1CF.zip for the CurseForge App, TMC Modpack 1.1.mrpack for every other launcher. Don't unzip it first.
My launcher offers to update mods
Dismiss it. Everything in the pack is locked to the server's versions.
Still stuck?
Ask on the Tenko Discord with a screenshot of the error.
